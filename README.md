# Data-Analyst-Internship-Task-1
Task 1 - Data Cleaning and Preprocessing using Python and Pandas
About the Project

This project focuses on cleaning and preprocessing the Customer Personality Analysis dataset using Python and Pandas.

Objective

To identify and handle common data quality issues, including missing values, duplicate records, inconsistent text formatting and incorrect data types.

Tools Used

Python

Google Colab

Pandas

NumPy

Matplotlib

Seaborn

Dataset

Customer Personality Analysis – Kaggle.

Work Performed

Loaded and inspected the raw dataset.

Identified missing values.

Filled missing Income values using median imputation.

Checked and removed duplicate records.

Standardized text values by removing extra spaces.

Converted customer dates into datetime format.

Standardized column names.

Verified data types and final data quality.

Exported the cleaned dataset as CSV.

Final Results

Total records: 2,240

Total columns: 29

Missing values after cleaning: 0

Duplicate records after cleaning: 0

Project Files

task_1_data_clean_and_preprocessing.ipynb – Python implementation.

marketing_campaign.csv – Original dataset.

cleaned_customer_personality.csv – Cleaned dataset.

Task_1_Data_Cleaning_and_Preprocessing_Report.docx – Project report.

Conclusion

The dataset was successfully cleaned and prepared for further data analysis using Python and Pandas.
